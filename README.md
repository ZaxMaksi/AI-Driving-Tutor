# AI Driving Tutor

Освітня веб-платформа для вивчення Правил дорожнього руху України та підготовки до теоретичного іспиту на отримання посвідчення водія з інтелектуальним ШІ-автоінструктором на базі **Google Gemini API**.

---

## Поточний статус проекту

- **Рівень готовності:** **Проект повністю реалізовано (100% готовність до демонстрації)**.
- **Пройдено етапів з ROADMAP:** **12 з 12** (Усі етапи виконано в повному обсязі).
- **Банк питань:** Наповнено базу офіційних екзаменаційних питань ПДР України (`seed_official_questions`).
- **Тестове покриття:** **41 автоматичний тест** (100% проходження) + наскрізний End-to-End сценарій.
- **Frontend збірка:** TypeScript + Vite білдяться без жодної помилки (`dist/` сформовано успішно).
- **OpenAPI / Swagger:** Повна інтерактивна специфікація API без жодної помилки або попередження.

---

## 🛠 Технологічний стек

### Backend
- **Python:** 3.12.10
- **Django:** 5.2.19 (Модульний моноліт)
- **Django REST Framework:** 3.18.3
- **PostgreSQL:** 18 (Docker-контейнер на порту `5433`)
- **Автентифікація:** JWT (SimpleJWT — access / refresh токени)
- **Документація API:** drf-spectacular (OpenAPI 3.0 / Swagger UI / Redoc)
- **Обробка зображень:** Pillow
- **Керування конфігурацією:** django-environ

### Frontend
- **React:** 19
- **TypeScript:** 5.8 / 7
- **Vite:** 8.3
- **Стилізація:** Tailwind CSS 4
- **Іконки:** Lucide React
- **Маршрутизація:** React Router DOM 7
- **HTTP-клієнт:** Axios з автоматичним оновленням JWT-токенів (interceptors)

### ШІ-інтеграція
- **SDK:** `google-genai` (v3.6.1)
- **Модель:** `gemini-2.5-flash`
- **Можливості:**
  - Генерація навчальних питань через Structured Outputs (Pydantic-валідація).
  - Персоналізоване пояснення помилок учня на основі точного нормативного контексту.
  - Консультації віртуального автоінструктора з ПДР України.
  - Захист від галюцинацій: ізоляція підрахунку балів від моделі, надання офіційних норм ПДР у промпт.

## Архітектура модулів Django (`backend/`)

1. **`users`** — реєстрація, авторизація, кастомна модель `User` (email замість username), профіль.
2. **`traffic_rules`** — база ПДР України (Постанова КМУ № 1306, усі 34 розділи, 297 пунктів), повнотекстовий пошук, імпорт.
3. **`questions`** — банк офіційних та ШІ-згенерованих питань, варіанти відповідей, зображення з перевіркою через Pillow.
4. **`testing`** — тестові сесії (іспит 20 питань, за розділом, змішаний), облік часу, перевірка відповідей сервером.
5. **`progress`** — зведена статистика користувача, прогрес за кожним розділом, рекомендації щодо повторення.
6. **`ai_tutor`** — ізольований сервісний шар роботи з Gemini API, журнал аудиту викликів `AIGenerationLog`.

## Швидкий запуск

### 1. Запуск бази даних PostgreSQL
```powershell
docker compose up -d
```
> Контейнер `ai_driving_tutor_db` працює на зовнішньому порту `5433` (щоб уникнути конфлікту зі службою Windows на 5432).

### 2. Запуск віртуального оточення
```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Застосування міграцій та імпорт нормативної бази ПДР
```powershell
python backend/manage.py migrate
python backend/manage.py import_traffic_rules
python backend/manage.py seed_official_questions
```

### 4. Запуск тестів
```powershell
python backend/manage.py test users traffic_rules questions testing progress ai_tutor
```

### 5. Запуск сервера розробки (Backend)
```powershell
python backend/manage.py runserver 8000
```

### 6. Запуск клієнтського додатку (Frontend)
```powershell
cd frontend
npm run dev
```
Клієнтський інтерфейс буде доступний за адресою: `http://localhost:5173/` (з налаштованим проксі на бекенд).
