# Словник та довідник REST API (v1)

Усі ендпоінти мають базовий префікс `/api/v1/`.
Формат обміну даними: `application/json`.
Автентифікація для захищених маршрутів: HTTP-заголовок `Authorization: Bearer <access_token>`.

---

## 1. Службові ендпоінти

- `GET /api/v1/health/` — перевірка працездатності та доступності API-сервісу.
- `GET /api/schema/` — схема специфікації OpenAPI 3.0 (JSON/YAML).
- `GET /api/docs/` — інтерактивна документація Swagger UI.
- `GET /api/redoc/` — інтерактивна документація Redoc.

---

## 2. Автентифікація та профіль (`/api/v1/auth/`)

- `POST /api/v1/auth/register/` — реєстрація нового користувача (`email`, `password`, `password_confirm`, `first_name`, `last_name`). Повертає JWT-токени та дані створеного облікового запису.
- `POST /api/v1/auth/login/` — авторизація за адресою електронної пошти та паролем. Повертає `access` (термін дії 60 хв), `refresh` (термін дії 7 днів) та об'єкт профілю користувача.
- `POST /api/v1/auth/token/refresh/` — отримання нового access-токена за дійсним refresh-токеном.
- `POST /api/v1/auth/logout/` — відкликання поточної сесії (приймає `refresh`).
- `GET /api/v1/auth/profile/` — отримання персонального профілю поточного користувача (захищений маршрут).
- `PATCH /api/v1/auth/profile/` — редагування імені та прізвища користувача (захищений маршрут).
- `POST /api/v1/auth/change-password/` — зміна пароля авторизованим користувачем.

---

## 3. Нормативна база ПДР України (`/api/v1/traffic-rules/`)

- `GET /api/v1/traffic-rules/sections/` — перелік усіх 34 розділів ПДР України із зазначенням кількості пунктів у кожному.
- `GET /api/v1/traffic-rules/sections/{number}/` — повний текст обраного розділу з усіма вкладеними пунктами (номери розділів від 1 до 34).
- `GET /api/v1/traffic-rules/points/{number}/` — отримання конкретного нормативного пункту правил за його номером (наприклад, `1.10`, `12.4`).
- `GET /api/v1/traffic-rules/points/search/?search=...` — повнотекстовий пошук за змістом та номерами пунктів ПДР України.

---

## 4. Банк питань та зображень (`/api/v1/questions/`)

- `GET /api/v1/questions/` — фільтрація та отримання списку питань (параметри: `section_number`, `difficulty`, `question_type`).
- `GET /api/v1/questions/{id}/` — перегляд питання для проходження тестування (**приховує** ознаку правильності `is_correct` у варіантах відповідей для захисту від підглядання).
- `GET /api/v1/questions/{id}/result/` — детальний розбір питання після завершення сесії (з розкриттям поля `is_correct` та нормативного обґрунтування).

---

## 5. Система тестування (`/api/v1/testing/`)

- `POST /api/v1/testing/start/` — створення нової тестової сесії (підтримувані режими: `exam`, `by_topic`, `mixed`, `ai_training`).
- `GET /api/v1/testing/sessions/` — історія проходження тестів авторизованого користувача.
- `GET /api/v1/testing/sessions/{id}/` — детальний перегляд обраної сесії з усіма наданими відповідями та помилками.
- `POST /api/v1/testing/sessions/{id}/answer/` — відправка відповіді на питання (`question_id`, `selected_option_id`, `time_spent_seconds`). Правильність відповіді перевіряється виключно сервером.
- `POST /api/v1/testing/sessions/{id}/finish/` — завершення тестування, розрахунок результату здачі ($\le 2$ помилок для іспиту) та автоматичне оновлення персональної статистики.

---

## 6. Прогрес та рекомендації (`/api/v1/progress/`)

- `GET /api/v1/progress/summary/` — зведена аналітика: загальна кількість пройдених тестів, складених іспитів, наданих відповідей та середній відсоток успішності.
- `GET /api/v1/progress/topics/` — детальний прогрес за кожним із 34 розділів ПДР (ознака засвоєння теми при успішності $\ge 90\%$).
- `GET /api/v1/progress/recommendations/` — топ-5 розділів із найбільшою кількістю допущених помилок та персоналізовані рекомендації щодо повторення.

---

## 7. AI Tutor (Gemini API) (`/api/v1/ai-tutor/`)

- `POST /api/v1/ai-tutor/generate-question/` — генерація нового навчального питання через Gemini API зі структурованою валідацією та збереженням у статусі `pending`.
- `POST /api/v1/ai-tutor/explain-mistake/` — формування розгорнутого педагогічного пояснення помилки студента з обов'язковою прив'язкою до норм ПДР із PostgreSQL.
- `POST /api/v1/ai-tutor/consult/` — консультація студента з віртуальним автоінструктором природною українською мовою.
- `GET /api/v1/ai-tutor/logs/` — журнал аудиту звернень до LLM поточного користувача.
